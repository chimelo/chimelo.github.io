行動変容コンサルティングオフィスTTA様 LP制作

行動変容コンサルティングオフィスTTA様のランディングページをデザインからコーディング・デプロイ・コラム機能開発まで一貫して制作。

Web DesignCodingLPBranding

概要

行動変容コンサルティングオフィスTTA様のランディングページを、デザイン・コーディング・デプロイ・コラム機能開発まで一貫して制作しました。

DiSC理論を活用した組織改善・人材育成サービスの魅力を伝え、問い合わせにつなげるためのLPです。

  • 公開サイトはこちら

クライアント

行動変容コンサルティングオフィスTTA 様

行動心理学に基づくパーソナリティアセスメントツール「DiSC」を活用し、医療機関・企業向けにコミュニケーション改善や組織力強化を支援されています。

制作内容

ランディングページ

訪問者が「TTAに相談したい」と思えるよう、サービスの全体像から実績・講師紹介までをストーリー構成で設計しました。

コラム機能

サービスの専門性を発信し、SEOにも寄与するコラム（ブログ）機能を開発しました。記事の投稿・管理がクライアント側で完結できる仕組みを構築しています。

デザインで意識したこと

  • 信頼感と温かさの両立: 紺×白ベースに夕焼けのビジュアルを使い、コンサルティングの信頼感と人に寄り添う温かさを表現
  • ストーリー構成: 「課題提起 → TTAが選ばれる理由 → サービス内容 → 実績・講師紹介 → お問い合わせ」の流れで、読み手の関心を段階的に引き出す設計
  • 視線誘導: セクションごとにメリハリをつけ、CTAボタンへ自然に導線を設計
  • レスポンシブ対応: スマートフォンでも読みやすいレイアウト設計

制作範囲

  • ヒアリング・要件定義
  • ワイヤーフレーム・構成設計
  • UIデザイン
  • コーディング（HTML / CSS / JavaScript）
  • デプロイ・公開対応
  • コラム（ブログ）機能の開発
